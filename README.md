# 🌾 KHET2KART

**Connecting Farmers Directly with Consumers & FPOs**

KHET2KART is a digital agricultural marketplace developed to reduce the gap between farmers and consumers by eliminating unnecessary middlemen. The platform enables farmers to sell produce directly, consumers to purchase fresh products at fair prices, and FPOs (Farmer Producer Organizations) to manage logistics, pooled lots, and farmer networks efficiently.

Built as a Smart India Hackathon (SIH) prototype, KHET2KART aims to create a transparent, technology-driven agricultural ecosystem that benefits every stakeholder in the supply chain.

---

## 🚀 Problem Statement

Indian farmers often face:

* Low profit margins due to multiple intermediaries
* Limited market access
* Lack of transparency in pricing
* Difficulties in logistics and order management

Consumers, on the other hand, pay higher prices while receiving limited information about product origin and quality.

KHET2KART addresses these challenges through a direct farm-to-market platform.

---

## 💡 Solution

KHET2KART provides:

* Direct Farmer-to-Consumer Marketplace
* Farmer Producer Organization (FPO) Management
* Order Tracking System
* Demand Board for Farmers
* Logistics Coordination
* Premium Membership Features
* Product Comparison Tools
* Wishlist & Cart Functionality
* Multilingual Support (Hindi Available)
* Analytics Dashboard for FPOs

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/psachdeva0108/KHET-KART.git
```

### Move to Project Directory

```bash
cd KHET-KART
```

### Install Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
npm run server
```

### Run Full Application

```bash
npm run dev:full
```
